# ShardSway

A simple ShardSway System for fail over.

ShardSway is built to be simple and practical, focusing on doing one thing well.

**Why ShardSway?**

- A simple ShardSway System for fail over

## Key Features

- A simple ShardSway System for fail over

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/ShardSway.git`
2. `cd ShardSway`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
